# Credit Card Fraud Detection

This project explores credit card transaction data and trains classification models to identify potentially fraudulent transactions. It includes exploratory data analysis, preprocessing, Random Forest and Logistic Regression training, model evaluation, a command-line prediction script, and a Streamlit dashboard.

> **Important:** This is an educational/demo project, not a production fraud-detection system. The Streamlit dashboard accepts only transaction time and amount and fills the 28 anonymized `V1`–`V28` features with zeros. Its prediction may therefore be unrepresentative. The CLI script accepts all 30 model features. Do not use either output as the sole basis for financial decisions.

## Project layout

| File or directory | Purpose |
| --- | --- |
| `dataset/creditcard.csv` | Dataset used by the scripts; expected to contain 30 features and a `Class` target column. |
| `dataset/archive dataset/`, `dataset/archive dataset.7z` | Additional copies of the dataset and its compressed archive. |
| `fraud_detection.py` | Loads and prints a basic dataset overview. |
| `eda.py` | Creates class, amount, and correlation plots and prints descriptive statistics. |
| `preprocessing.py` | Splits the data (80/20, stratified), scales features, and saves `scaler.pkl`. |
| `random_forest.py` | Trains and evaluates a class-balanced Random Forest; saves `random_forest_model.pkl`. |
| `model.py` | Trains and evaluates a class-balanced Logistic Regression baseline. |
| `evaluation.py` | Evaluates the Random Forest with ROC-AUC and average precision and saves ROC and precision-recall plots. |
| `predict.py` | Runs an interactive prediction using all 30 input features. |
| `app_backup.py` | Root-level Streamlit dashboard for transaction analysis, dataset analytics, and model metrics. |
| `FraudShield-AI/` | Contains an additional dashboard copy and its README. Its expected dataset and model files are not included in that subfolder. |
| `random_forest_model.pkl`, `scaler.pkl` | Serialized model and scaler used by prediction and dashboard scripts. |
| `*_distribution.png`, `normal_vs_fraud_amount.png`, `top_correlations.png` | Exploratory-analysis plots generated by `eda.py`. |

The target column is `Class` (`0` for normal and `1` for fraud). The model expects the feature columns `Time`, `V1`–`V28`, and `Amount`. Keep the CSV at `dataset/creditcard.csv`, relative to the project root.

## Setup

Run these commands from the project root:

```bash
python -m venv .venv
```

Activate the environment:

```powershell
.\.venv\Scripts\Activate.ps1
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

Install the project dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the dashboard

```bash
streamlit run app_backup.py
```

The dashboard loads the dataset, scaler, and model from the project root. It shows dataset counts and class proportions, allows a simplified time-and-amount analysis, and displays Random Forest evaluation metrics.

## Run the scripts

```bash
python fraud_detection.py
python eda.py
python random_forest.py
python evaluation.py
python model.py
python predict.py
```

- `eda.py` saves charts in the project root and opens them for display.
- `random_forest.py` imports `preprocessing.py`, which creates the train/test split and rewrites `scaler.pkl`; training then rewrites `random_forest_model.pkl`.
- `evaluation.py` imports the preprocessing and Random Forest modules, so it also runs preprocessing and trains/saves the Random Forest before calculating its evaluation metrics.
- `model.py` runs the Logistic Regression baseline using the same preprocessing pipeline.
- `predict.py` prompts for `Time`, each feature from `V1` through `V28`, and `Amount`, in that order.

The saved model and scaler should be generated by the same training run. Retrain before relying on existing `.pkl` files, especially after changing the dataset or dependencies.

## Dependencies

Python packages are listed in [`requirements.txt`](requirements.txt). The project uses Streamlit for the dashboard; pandas and NumPy for data handling; scikit-learn for preprocessing, modeling, and metrics; joblib for model persistence; and Matplotlib for plots.
